## Основная страница
- Сама по себе она никуда не отправляет никакие запросы, в отличие от других
- Юзернейм меняется через start.html | ОС, браузер и его движок определяются автоматически
- Содержание и количество секций меняется через sectionsData.js (они автоматически выстраиваются по 4 в ряд и автоматически через каждые 4 элемента добавляется полоса (если это не кастомные элементы))
- Новые команды для псевдоконсоли можно добавлять через commandsData.js (есть автопополняемая команда help)
- Новые иконки можно брать с помощью этой же псевдоконсоли: icons название иконки на английском
- В настройках браузера ее можно сделать стартовой, открыв и скопировав ссылку
- Встроенный плеер при нажатии на Play включает рандомную композицию из tracksData.js

Псевдоконсоль можно взять в фокус с помощью Tab, автозаполнение команд - тоже Tab

Команды myip и ip -.-.-.- могут иногда блокироваться по CORS

Дизайн адаптирован под телефоны (но с иконками могут быть проблемы)

## Notes
- Пример базы заметок есть в папке по пути pages/notes
- В заметке "Возможности" перечислены горячие клавиши и просто markdown замены, которые я добавил
- Можно перетаскиванием менять порядок заметок
- Кнопки справа: добавить новую заметку, закончить редактирование заметки, удалить открытую заметку
- Кнопки слева: открыть .json файл, сохранить .json файл (автосохранения нет)
